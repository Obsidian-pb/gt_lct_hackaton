# Примечания по базе данных

## 21.09.2026: Поля карточки (обязательные)

**Основное**

- Номер карточки (формируется по заполнению полей `Группа происшествий`, `Признак 1`, `Признак 2`, `Признак 3`)


**Данные карточки**

- Номер карточки в системе 112
- Дата и время сохранения
- Кто зарегистрировал карточку
- Дата и время контроля
- Кто проводил контроль

**Телефоны**

- АОН - номер телефона определенный автоматически
- Предоставленный заявителем номер телефона
- На место - телефон для связи на месте происшествия (если заявитель не находится на месте)

**Заявитель**

- Информация о заявителе (ФИО)
- статус (участник, очевидец, родственник)

**Адрес:**

- Формализованный по базе Яндекс:
    - Страна
    - Субъект
    - Населенный пункт
    - Объект
    - Округ
    - Район
    - Улица
    - Дом
    - Корпус
    - Строение
    - Квартира
    - Подъекзд
    - Этаж
    - Код (домофона)
    
- Координаты
- Описательный адрес
- Точа на карте

**Что случилось:**

- Группа происшествий
- Признак 1
- Признак 2
- Признак 3

**Описание:**

- Неформализованная информация о происшествии
- Информация из карточки ВИС (*что бы это ни значило, думаю нужно сделать текстовое поле*)
- Отметки о контроле

**Дополнительно**

(Тут тне понятно - возможно должны быть булевы поля)

- Пострадавшие
- Нет на месте/Отказ отт скорой
- Нет доступа/Заблокированные


### Связи с другими таблицами

**Дополнительные сведения:**

В таблице хранятся записи дополняющие группу **Что случилось:**. Для каждой группы происшествий набор данных может быть разным.

Соответственно, каждая запись из таблицы Events (События) должна иметь свой набор дополнительных сведений. При заполнении Карточки, в зависимости от группы происшествий, соответствующий набор добавляется и ей. 

**Привлекаемые службы**

Для каждой записи в Events (События) должна быть создана запись в таблице Services (Службы).
