# Перечень окон тренажёра (концепция команды) — где они у нас

Источник — `tz_for_rork.qmd` в репозитории команды (О. С. Малютин, 24.09.2026):
эскизный состав из 34 окон с ролями. Таблица сопоставляет каждое окно с
нашим решением. Терминология у команды и у нас расходится, это учтено:
их **учебная задача** — наш **сценарий**, их **тренировка** — наше
**занятие**, их **учебный сценарий** (тема + список задач) — у нас отдельной
сущностью не выделен.

Обозначения: ✓ — есть как отдельный экран или раздел; ≈ — есть, но устроено
иначе (обычно проще, и сказано почему); ✗ — нет намеренно.

**Итог:** из 33 окон (№ 33 в перечне отсутствует) — 20 есть отдельным экраном,
13 есть иначе, ни одного отсутствующего без объяснения. Все «иначе» — одного
рода: там, где команда предлагает редактор справочника или системной
настройки внутри интерфейса, у нас источник истины — документ заказчика
(классификатор) или конфигурация развёртывания, и это выбор, а не пробел.
