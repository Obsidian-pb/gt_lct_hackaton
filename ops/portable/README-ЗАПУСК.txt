ТРЕНАЖЁР ОПЕРАТОРОВ И ДИСПЕТЧЕРОВ СИСТЕМЫ-112 — ПЕРЕНОСНОЙ КОМПЛЕКТ

Комплект работает без установки. Всё нужное лежит в этой папке: база
данных, языковая модель, приложение. В систему ничего
не записывается; удалить комплект — значит удалить папку.

ЧТО НУЖНО
  - Windows 10 или 11, 64-разрядная.
  - 8 ГБ памяти (языковая модель занимает около 3 ГБ).
  - 6 ГБ свободного места на диске.
  - Права администратора НЕ нужны и даже мешают: см. ниже.

ЗАПУСК
  1. Скопируйте папку на диск (не запускайте прямо с флешки: база данных
     пишет на диск, с флешки это медленно).
  2. Дважды щёлкните start.cmd. Обычным щелчком, не «от имени
     администратора»: PostgreSQL отказывается работать с правами
     администратора — это его защита.
  3. Первый запуск — 1–2 минуты: создаётся база, загружаются учебные вызовы.
     Дальше открывается браузер с адресом http://127.0.0.1:8090/
  4. Языковая модель загружается в память ещё 1–3 минуты. До этого
     тренажёр работает полностью, только текстовый разбор от нейросети
     приходит с задержкой.

УЧЁТНЫЕ ЗАПИСИ
  admin, teacher, student, student2 — пароль совпадает с логином.
  Ещё преподаватели и обучающиеся заводятся администратором в разделе
  «Пользователи».

ДОСТУП ИЗ КЛАССА
  По умолчанию тренажёр открыт только на этом компьютере. Чтобы ученики
  заходили со своих мест по сети:
  1. Создайте рядом файл settings.cmd со строкой  set "WEB_HOST=0.0.0.0"
     (образец — settings.example.cmd).
  2. Запустите start.cmd. В окне появятся адреса вида
     http://192.168.10.10:8090/ — их и диктуют ученикам.
  3. При первом запуске Windows спросит про брандмауэр — разрешите доступ
     в частных сетях. Для этого нужны права администратора (один раз).
     Если окно не появилось или доступ не разрешён, ученики увидят
     «не удаётся подключиться» — тогда правило добавляет администратор
     компьютера: входящие TCP на порт 8090.
  База данных и языковая модель наружу не открываются ни при каких
  настройках — только веб-интерфейс.

ОСТАНОВКА
  Дважды щёлкните stop.cmd. Данные сохраняются в папке data\ и будут
  на месте при следующем запуске.

РЕЗЕРВНЫЕ КОПИИ
  Снимаются сами: при остановке (stop.cmd) и при каждом запуске перед
  обновлением схемы базы. Лежат в data\backups\, хранятся последние 14;
  свежесть видна администратору в разделе «Состояние». Восстановление
  из копии — при работающем комплекте, в отдельном окне командной строки
  из папки комплекта:
    runtime\pgsql\bin\pg_restore.exe -h 127.0.0.1 -p 5433 -U trainer
      -d trainer --clean --if-exists data\backups\latest.dump
  затем stop.cmd и start.cmd.

ЕСЛИ ЧТО-ТО НЕ ТАК
  Все журналы — в папке data\logs\:
    initdb.log     создание базы при первом запуске
    postgres.log   работа базы данных
    setup.log      миграции и загрузка учебных данных
    llm.log        языковая модель
  Окна «DDS112 server» и «DDS112 model» свёрнуты на панели задач —
  в них видно, что происходит прямо сейчас.

  «Окно открыто от имени администратора»
      Закройте и запустите start.cmd обычным двойным щелчком.
  Порт 8090 занят другой программой
      Создайте рядом файл settings.cmd со строкой  set "WEB_PORT=8091"
      (образец — settings.example.cmd) и запустите снова.
  Модель не отвечает, разбор не приходит
      Откройте окно «DDS112 model». Чаще всего не хватило памяти —
      закройте тяжёлые программы. Без модели тренажёр работает
      полностью, кроме текстового разбора.
  Браузер не открылся сам
      Откройте вручную http://127.0.0.1:8090/

ОБНОВЛЕНИЕ
  Обновление приходит файлом dds112-update.zip. Остановите комплект
  (stop.cmd), распакуйте архив поверх этой папки с заменой файлов
  и запустите start.cmd — схема базы обновится сама, данные сохранятся.

ЧТО ВНУТРИ
  runtime\python   Python 3.12 и библиотеки приложения
  runtime\pgsql    PostgreSQL 17
  runtime\llama    сервер языковой модели llama.cpp
  models\          файл модели (Qwen3 4B); можно заменить другим .gguf
  app\backend      серверная часть тренажёра
  app\web          интерфейс и озвученные учебные вызовы
  data\            база данных, журналы, ключ подписи — создаётся при запуске
