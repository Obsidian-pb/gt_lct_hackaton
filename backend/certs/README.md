# Корневые сертификаты

`russian_trusted_root.pem` — корневой и промежуточный сертификаты НУЦ Минцифры
(Russian Trusted Root CA и Russian Trusted Sub CA), загружены с https://gu-st.ru.

Нужны для проверки TLS-цепочки GigaChat: в стандартных хранилищах доверия их
нет, и без них соединение обрывается с `CERTIFICATE_VERIFY_FAILED`.

Файл передаётся только клиенту GigaChat через `GIGACHAT_CA_BUNDLE`, а не
добавляется в системное хранилище. Для этих соединений доверенным оказывается
ровно один удостоверяющий центр — это строже, чем доверие по умолчанию.

Сертификаты публичные, секретом не являются.
