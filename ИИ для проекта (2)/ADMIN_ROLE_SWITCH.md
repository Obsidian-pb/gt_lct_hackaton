# Переключение учебных ролей администратором

В панели администратора добавлено управление учебными ролями участников общей тренировки.

## Как использовать

1. Откройте `/admin` и войдите как администратор.
2. В боковом меню откройте **«Учебные роли»**.
3. Выберите подготовленную тренировку и нужного участника.
4. Назначьте одну из ролей:
   - Оператор 112;
   - Диспетчер 112;
   - Диспетчер службы;
   - Роль не назначена.
5. Для роли «Диспетчер службы» дополнительно выберите службу.

Администратор может назначить учебную роль и самому себе, если его имя добавлено в состав тренировки. Системная роль «Администратор» при этом не меняется.

Учебные роли меняются только до запуска тренировки. После запуска они блокируются, потому что сервер уже создаёт операторские сессии, очереди карточек и маршрутизацию между рабочими местами.
