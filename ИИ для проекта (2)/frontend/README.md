# React-интерфейс ИИ-модуля

React 19, JSX и esbuild. Начальный экран, меню, панель преподавателя и мастерская карточек реализованы компонентами React. API GigaChat и валидация остаются в Python. Ключ модели не попадает в браузер.

## Обычный запуск

Открыть `../START.cmd`. Готовая сборка включена в `../ui/react/app.js`, поэтому для просмотра Node.js и установка пакетов не нужны. Начальный экран: http://127.0.0.1:8878/ .

## Разработка

Нужен Node.js 20 или новее с npm. В этой папке:

```sh
npm ci
npm run build
```

После изменения JSX пересоберите интерфейс и обновите браузер. `npm run watch` пересобирает при сохранении; Python-сервер запускается отдельно через `START.cmd`. Изменения Python требуют перезапуска сервера.

## Структура

- `src/main.jsx` — React root, начальный экран и выбор страницы.
- `src/Shell.jsx` — общая навигация, профиль, выход.
- `src/Teacher.jsx` — разделы преподавателя и сохранённые тренировки.
- `src/Cards.jsx` — генератор, список, редактор, проверка и история.
- `src/Classification.jsx` — зависимые признаки, отдельные условия, справочник служб и исходные правила.
- `src/ServicesDock.jsx` — нижняя полоса вкладок служб по `card.svg`. Показывает состав текущей карточки; нажатие открывает панель вверх с данными происшествия и основанием выбора, не меняя состав. Кнопка с двумя стрелками открывает справочник с поиском. Изменения вступают в силу только после «Применить состав»; Escape и крестик отменяют неприменённые изменения. Утверждённые службы можно просматривать без редактирования.
- `src/service-routing.js` — автовыбор по классификатору и отдельные ручные решения преподавателя. Неподдерживаемые условия остаются на ручную проверку. Проверка: `node tests/check_service_routing.mjs` из папки ИИ-модуля.
- `src/workshop-store.js` — очередь запросов, локальные записи и версии утверждения; подключение через `useSyncExternalStore`.
- `src/api.js` — HTTP-клиент существующего Python API.
- `../ui/*.css` — согласованный дизайн; `hero-*.svg` — материалы макета.

Маршруты `/`, `/teacher` и `/cards` отдают общую React-страницу. Переходы между страницами обычные, разделы преподавателя используют hash. Не требуется React Router или отдельный Node-сервер. Подход соответствует [официальному руководству интеграции React](https://react.dev/learn/add-react-to-an-existing-project).

Совместимость: ключ `giik.card-workshop.v1` и схема записей не изменены. Старые карточки, история утверждений и приостановленная очередь читаются новым интерфейсом на том же адресе и порте. Исходные файлы прежнего интерфейса карточек оставлены как справочные и не подключаются на новых страницах.

Отдельный прежний учебный стенд `/training` сохранён на обычном JavaScript: оба варианта разговора, микрофон и проверка работ продолжают работать. Он не переписан на React в рамках переноса новых экранов. Назначение групп, реальная авторизация и сообщения пока не подключены.

Сборка локальная, без CDN и внешних скриптов. Python раздаёт только явно разрешённые ресурсы; `frontend`, `node_modules` и конфигурация модели через HTTP недоступны.
