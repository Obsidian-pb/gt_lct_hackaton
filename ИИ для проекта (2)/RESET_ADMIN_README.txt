RESET_ADMIN.cmd — сброс забытого логина/пароля администратора.

1. Дважды нажмите RESET_ADMIN.cmd.
2. Введите ДА для подтверждения.
3. В браузере нажмите «Сбросить администратора».
4. Откроется «Первичная настройка администратора» — создайте новый логин и пароль.

Сброс удаляет только локальную учётную запись и активную сессию администратора в этом браузере.
Карточки, сценарии, тренировки, результаты, пользователи и учебные роли сохраняются.
