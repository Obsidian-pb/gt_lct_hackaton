# Проверка перехода на REST API

Дата: 27.09.2026.

## Результат

- 46 прикладных маршрутов REST, плюс health и OpenAPI.
- Python unittest: 99 тестов, 93 прошли, 6 тестов Windows PowerShell пропущены в Linux.
- 16 новых HTTP-тестов проверяют REST с отключённым прежним RPC: полный цикл преподаватель → обучающийся → оценка, типы/параметры, токены, CORS, методы/статусы, проекции, карту и OpenAPI.
- Общий JavaScript-клиент проверен отдельно: URL, методы, кодирование русских имён, JSON, ошибки с request_id, тайм-аут без автоматического повтора.
- Браузерная проверка Chromium: карточки, преподаватель, обучающийся, сценарии, учебный прототип и документация. Генерация карточки/эталона использовала тестовые ответы ИИ. Зафиксировано 19 REST-запросов и 0 запросов на прежний `/api`; сервер запущен с отключённым RPC.
- React пересобран; синтаксис готового bundle и изменённых JS-файлов проверен.
- BOM у PowerShell-файлов сохранён. Новая CMD-обёртка ASCII с CRLF.
- Все внутренние операции интерфейса сопоставлены с маршрутами; OpenAPI и клиентские таблицы соответствуют api_contract.py.
- Учебные данные, классификатор, исходные геоданные OSM, настройки ИИ-провайдеров и комплект Windows-инструментов сохранены из предыдущей исправленной сборки.

## Ограничения

Живые вызовы AITUNNEL/OpenAI и Piper с реальным голосовым движком не выполнялись. Тесты не расходовали пользовательские API-токены. Windows-обёртки не запускались в этой среде.

Сервер остаётся локальным. Интеграционный токен общий, не заменяет пользовательскую авторизацию. Продуктовые роли, общая БД и сетевое развёртывание принадлежат следующему этапу командной интеграции.

REST_API.md описывает запуск, авторизацию клиента, маршруты и примеры. START.cmd запускает обычный интерфейс; api_server.py запускает только API.
