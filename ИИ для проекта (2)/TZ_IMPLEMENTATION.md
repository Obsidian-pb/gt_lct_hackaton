## REST-интеграция

Все новые маршруты документированы в `/api/v1/openapi.json` и `openapi.json`. Основные ресурсы: `/scenarios`, `/trainings`, `/training-desks/{student}`, `/trainings/{id}/cards/{card_id}/routing`, `/trainings/{id}/cards/{card_id}/actions`, `/works/{id}/percentage-decision`, `/reports/insights`, `/materials`, `/services`.

Сценарии и тренировки лежат в `data/curriculum/` рядом с существующими учебными сессиями. Состояния тренировок: `prepared → active → completed`; утверждённый сценарий не меняется. Доменная логика сосредоточена в `curriculum.py` и не зависит от HTTP: при подключении PostgreSQL команда может заменить хранение без смены интерфейсного контракта. Старые семипольные упражнения открываются через `/teacher#legacy-builder`; новые тренировки составляются из полных опубликованных карточек.

## Проверка и границы

- Проверить Python: `PYTHONPATH=.:tests python -m unittest discover -s tests -p 'test_*.py'`.
- Собрать интерфейс из `frontend`: `npm ci`, затем `node build.mjs`.
- Новые роли проверяются `tests/test_curriculum.py` и `tests/check_curriculum_ui.mjs`; браузерный тест использует только поддельный провайдер и временные данные.
- Авторизация пользователей, реальные учётные записи, PostgreSQL, аудит и системный мониторинг требуют интеграции с компонентами других участников команды. Локальный REST токен и ввод ФИО не удостоверяют роль пользователя.
- Карта берёт адреса и геометрию из `ui/geo/addresses.json` и `ui/geo/map.json`. Центр и подписи определяются по набору; сейчас в архиве имеется только учебный набор Железногорска. Для Москвы потребуются её координаты/граница, здания, дороги и адресный индекс такого же формата. Неполное покрытие OSM допустимо.
- Озвучка зависит от установленного Piper либо браузерного голоса. Реальная IP телефония, движение подразделений по карте и ИИ-участники коллективной тренировки относятся к последующим этапам ТЗ.
- Методическая база принимает ссылки на документы HTTP(S), сами файлы не загружаются в этот локальный сервер. Административные системные переключатели не считаются реальными настройками до подключения серверной части команды.
