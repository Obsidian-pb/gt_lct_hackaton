## 2. Что нужно сделать вам

### Шаг 1. Реальный ключ ИИ (без него генерация вернёт 502)

1. Запустите `ai_service\SETUP_ENV.cmd` — создаст `ai_service\.env` (токен уже вписан)
   и добавит `AI_SERVICE_URL`/`AI_SERVICE_TOKEN` в `backend_new\.env`.
2. Отредактируйте `ai_service\.env`:
   - `AI_API_KEY=<ваш ключ>`;
   - для OpenAI-совместимого API — `AI_BASE_URL` (например `https://api.aitunnel.ru/v1`)
     и точное имя `AI_MODEL`;
   - для GigaChat — `AI_PROVIDER=gigachat`, ключ авторизации, при необходимости `AI_SCOPE`.
3. Перезапустите стенд: `frontend_new\STOP.cmd`, затем `frontend_new\START.cmd`
   (или по частям: `ai_service\START_AI.cmd` → backend → frontend).

### Шаг 2. Наполнить классификатор (dev-БД пуста)

```
cd backend_new
.venv\Scripts\python.exe scripts\import_classifier_xlsx.py
```

Скрипт идемпотентный, источник: `TZ/datasets/клссы событий.xlsx`. Без него каскады
«группа → признаки» в задачах и мастерская классификатора будут пустыми.

### Шаг 4. Сценарии 1–4 ТЗ (с реальным ключом)

1. **Сценарий 1 — настройка системы** (admin): пользователи и роли (`users.html`),
   справочники и классификатор (`reference.html`), мониторинг/настройки/аудит (`system.html`).
2. **Сценарий 2 — учебная среда** (teacher): задача + ИИ-генерация и эталон (`tasks.html`),
   сценарий из задач (`scenarios.html`), тренировка с участниками и активацией (`trainings.html`).
3. **Сценарий 3 — оператор-112** (student): старт сессии → «Принять вызов» → заполнение
   карточки → диалог с заявителем (ИИ) → «Сохранить и отправить» → машинная оценка;
   преподаватель может дополнительно запустить «🤖 Оценка ИИ».
4. **Сценарий 4 — диспетчеры** (окно 36): ДДС принимает и направляет в службу;
   диспетчер службы отрабатывает карточку; исходящий звонок в службу (ИИ, помехи канала);
   итоговая оценка в `cards.html`.

## 3. Известные ограничения

- Голосовой ввод работает в Chrome/Edge (SpeechRecognition); в других браузерах —
  только ручной ввод и озвучивание.
- `ai_service` слушает только `127.0.0.1:8890` локально; в контейнерах — внутренняя сеть compose.
- Микросервис stateless: история диалога хранится на клиенте (JS) и передаётся в теле запроса.
