# Баннеры экрана подготовки

Экран подготовки получает тип происшествия непосредственно из выбранного классификатора.
Фотографии лежат в этой папке и доступны как `/banners/<имя>.png`.

Для точной привязки новых фотографий отредактируйте `banner-map.json`:

```json
{
  "class_ids": {
    "1010101": "fire-trash",
    "2010101": "road-crash"
  },
  "categories": {
    "1": "fire-default",
    "2": "road-default"
  }
}
```

В `class_ids` ключ — точный ID строки классификатора, значение — имя PNG без расширения.
`categories` используется только как запасной вариант для всей категории.
Точные привязки имеют приоритет. Старые встроенные баннеры сохранены для совместимости.
