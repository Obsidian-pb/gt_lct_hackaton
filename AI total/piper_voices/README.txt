Локальные голоса Piper для учебного интерфейса.

Поддерживаются прежние русские голоса проекта:
- ru_RU-irina-medium.onnx + ru_RU-irina-medium.onnx.json
- ru_RU-denis-medium.onnx + ru_RU-denis-medium.onnx.json
- ru_RU-dmitri-medium.onnx + ru_RU-dmitri-medium.onnx.json

По умолчанию заявитель озвучивается первым доступным голосом (приоритет — Ирина).
Самих моделей в присланном архиве не было, поэтому они сюда не добавлены.
Интерфейс автоматически использует Piper, когда модель и runtime Piper доступны;
иначе используется системный русский голос браузера.
