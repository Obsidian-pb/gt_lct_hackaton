# Рекомендации по ведению папки workflow

Пиши в этой папке ход выполнения работы

Каждый отчет должен называться step_N.md, где N - номер шага, увеличивающийся раз за разом.

В начале каждого файла дописывай дату, время создания и идентификатор модели которая выполняла работу.

# Ограничения

Старайся не вставлять в отчеты сам код - достаточно ссылки на файл. Однако этим правилом можно пренебречь, если ты считаешь, что это позволит в дальнейшем сэкономить время и токены при чтении исходных файлов с кодом.
