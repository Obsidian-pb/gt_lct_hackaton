REST API учебного симулятора

Версия 1.0.0 · Базовый путь /api/v1

Скачать OpenAPI · Проверить сервер · Открыть симулятор

GET читает данные. POST создаёт задание или выполняет операцию. PUT сохраняет карточку, заметку или решение. Успешный ответ: {"data": …, "request_id": "…"}. Ошибка: {"error":{"code":"…","message":"…"},"request_id":"…"}.

Интерфейс передаёт X-UI-Token. Для отдельного клиента задайте на сервере TRAINING_API_TOKEN и передавайте его как Authorization: Bearer …. Это отдельный токен вашего симулятора. Ключ AITUNNEL/OpenAI хранится только на сервере.

Это локальный интеграционный сервер. Общий токен не разделяет роли преподавателя и обучающегося. Пользовательская авторизация и производственная база данных подключаются командой отдельно.

Пример запроса

GET /api/v1/tasks
Authorization: Bearer ВАШ_ТОКЕН_СИМУЛЯТОРА

Полные параметры находятся в OpenAPI и REST_API.md в папке проекта. Запросы к ИИ не повторяются автоматически после тайм-аута: сначала проверьте состояние сохранённых данных.
